# Everyday Things, Two Lines, Longer Run

Entry for the make.fun bounty [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.py` (stdlib only, no network) writes a two-line explanation of a traffic jam to `/output/entry.txt`: line 1 explains a traffic jam to a 10-year-old through a single vivid analogy — a school hallway at the final bell, a hundred kids squeezing through one door — and line 2 says honestly what the analogy maps and what it leaves out.

Run it with `python3 main.py`.
